# `ComposedMenu`

A popup that wraps a [`Menu`](./10-Menu.md). Use this for standalone menus
anchored to a button or other control.

- Inherits [`Popup`](./10-Popup.md)

## Slots

| name | description     |
| ---  | ---             |
|      | The menu items |

## CSS Parts

| name   | description        |
| ---    | ---                |
| `menu` | The internal menu |

## Properties

| name    | description              |
| ---     | ---                      |
| `$menu` | The internal `Menu`      |

Inherits all [`Popup`](./10-Popup.md) properties.
