# `List`

- Mixes [`InternalsAttached`](./20-InternalsAttached.md)

`List` is a static container with the `list` role that has no keyboard-
navigation or roving focus. Use [`ListBox`](./10-ListBox.md) with options for
an interactive selection list.

## CSS Parts

| name    | description        |
| ---     | ---                |
| `items` | The slot container |
