# Base

Base components and mixins live in `@/src/base/`. They implement behavior and
accessibility only, without any styles, and are meant to be extended by design
systems such as [Material You Expressive](../05-Material_You_Expressive/00-Overview.md)
and [Windows 98](../06-Windows_98/00-Overview.md).
